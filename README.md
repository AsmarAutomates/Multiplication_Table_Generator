
# Multiplication Table Generator

 A simple Java program that generates the multiplication table for a number entered by the user.

 ## 📌 Description

 The **Multiplication Table Generator** is a beginner-friendly Java program that demonstrates how to:

 - Take user input using `Scanner`
- Use a `for` loop
- Perform basic multiplication
- Display formatted output
- Close the `Scanner` after use

 The program generates the multiplication table from **1 to 10** for the number provided by the user.

 ## 🛠️ Technologies Used

 - **Java**
- **Java Scanner**
- **For Loop**

 ## 🚀 How It Works

 1. The program asks the user to enter a number.
2. The user enters an integer.
3. A `for` loop runs from `1` to `10`.
4. The program multiplies the entered number by the current loop value.
5. Each multiplication result is displayed on the console.
6. The `Scanner` is closed after the program finishes.

 ## 💻 Example

 ### Input

```
Enter the number to print its multiplication table
5
```

 ### Output

```
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

 Download the project to your local machine.

 Open the project in a Java-compatible IDE such as IntelliJ IDEA, Eclipse, or VS Code.
